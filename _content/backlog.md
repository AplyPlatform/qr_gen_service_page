# 질문 백로그

답할 질문의 대기열. 우선순위: **노출 있고 순위 낮음 > 노출 있고 전용 페이지 없음 > 추정 수요**.
2026-10-20 현재 서치 콘솔·서치어드바이저가 등록 전이라 모든 행이 "추정 수요"다.
등록 후 검색어 데이터가 쌓이면(약 4주) 근거 열을 실제 노출·순위로 바꾸고 다시 정렬한다.
